# Clínica Essenciale Saúde e Estética

Landing page institucional criada a partir da arquitetura do projeto de referência, com identidade, conteúdo, imagens e experiência totalmente adaptados para a Clínica Essenciale.

## Executar localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## Validação

```bash
npm run typecheck
npm run build
```

## Conteúdo editável

Telefone, WhatsApp, endereço, equipe, tratamentos, resultados e perguntas frequentes estão centralizados em:

```text
src/data/clinicData.js
```

As imagens estão organizadas em:

```text
public/images/essenciale/originals
public/images/essenciale/optimized
public/images/essenciale/generated
```
